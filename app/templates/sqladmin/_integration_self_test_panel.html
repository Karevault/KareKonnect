Meta test numbers vs production

Developer / “send to test number” flows are for building and QA. Real patients and production traffic should use your verified WhatsApp Business setup after Meta review and number verification — not the temporary test identities alone.

Webhooks reference — copy all callback URLs and run webhook self-tests.

Twilio webhook for SMS (and WhatsApp via Twilio)

Single phone number: Twilio Console → Phone Numbers → choose the number → Messaging configuration → “A message comes in” → Webhook → URL https://<your-host>/webhooks/twilio/inbound → HTTP POST.
Messaging Service: add your numbers as senders on the service; configure inbound per Twilio’s Messaging Service docs (webhook can be on the service or linked numbers).
